# 文庫本テンプレート 要求・要件

## 概要

Vivliostyle で文庫本（A6 判・縦組み）の PDF を Markdown から組むためのテンプレートである．
小説・随筆など，縦組みの読み物を同人誌として頒布する用途を主眼に置く．
本文書は要求（why）・要件（what）・用語を固定し，設計（how）は `docs/notes/` に委ねる．

## 背景と要求（why）

- 解決したい課題．
  縦組みの文庫本を組むには，版面の計算・柱とノンブルの配置・ルビ・縦中横・
  会話文の天付きといった約束事を CSS へ落とす必要がある．
  原稿を書くたびにこれらを組み直すのは負担が大きい．
- 価値提案．
  執筆者は Markdown の原稿と書誌情報だけを書けばよく，組版の約束事はテンプレートが担う．
  版面は「文字サイズ・字数・行数・のど」の 4 値から算出し，判型の変更に追随する．
  横組みの技術書テンプレート `tomio2480/techbook-template` と同じ運用を縦組みで提供する．
  運用とは GitHub Actions によるビルド・Markdown lint・Dependabot を指す．
- 改良を重ねても変えない価値基準．
  原稿は Markdown のまま保つ．組版のために原稿へ HTML を書かせる範囲は最小に留める．
  版面はテーマ CSS 冒頭の変数だけで調整できる状態を保つ．

## 用語集（ユビキタス言語）

表 1. 用語と意味

| 用語 | 意味 |
| --- | --- |
| 文庫本 | A6 判（105 mm × 148 mm）の書籍．本テンプレートの既定の判型 |
| 縦組み | 文字を上から下へ，行を右から左へ進める組み方．CSS の `vertical-rl` |
| 右綴じ | 背が右にある綴じ方．縦組みの書籍の標準．奇数ページが見開きの左に来る |
| 版面 | 本文を組む領域．1 行の字数と 1 ページの行数で決める |
| 行長 | 1 行の長さ．縦組みでは天地方向の版面の長さ |
| 行送り | 隣り合う行の中心間の距離．文字サイズ × 行間倍率 |
| 天・地 | ページの上端・下端 |
| のど・小口 | 綴じ側の余白・その反対側の余白 |
| 柱 | ページ上部に置く書名や章題 |
| ノンブル | ページ番号 |
| 行取り | 見出しに割り当てる行数．4 行取りなら本文 4 行分の幅を使う |
| 縦中横 | 縦組みの中で 1〜2 字の数字などを横組みで 1 字分に収める組み方 |
| 天付き | 段落の先頭を字下げせず，天から組むこと．会話文に使う |
| 傍点 | 強調のために文字の横へ打つ点（ゴマ） |
| 扉 | 書名と著者名だけを組む冒頭のページ |
| 奥付 | 書名・発行日・著者・発行者などを記す末尾のページ |

## 要件（what）

### 機能要件

- Markdown（VFM）の原稿から，A6 判・縦組みの PDF を 1 コマンドで生成する．
- 版面は文字サイズ・1 行の字数・1 ページの行数・のどの余白の 4 値で決める．
  天地と小口の余白はこの 4 値から算出する．
- 柱とノンブルを小口側へ置く．左ページは章題，右ページは書名を柱とする．
- 扉・目次・奥付のページには柱とノンブルを出さない．
- 目次はビルドが生成する．扉と奥付は目次に載せない．
- 章題は改ページして行取りで組む．節題も行取りで組む．
- 段落は 1 字下げとし，開き括弧で始まる段落は天付きにする．
  原稿冒頭の全角空白は取り除き，字下げを二重にしない．
- 全角文字の間の改行は詰め，原稿の折り返しが紙面へ空白として残らないようにする．
- 1〜2 桁の半角数字と「!?」などの 2 字の並びは自動で縦中横にする．
  除外したい箇所は `no-tcy` クラスで指定できる．
- ルビ・傍点・図・表・コードブロック・章末注を縦組みの中で組める．
- 書名と著者名は `config/book.yaml` を単一の出所とし，扉・奥付・柱・PDF の文書情報へ流し込む．
- GitHub Actions で，テストは常に，PDF は指示したときだけ生成する．
  `v*` タグで Release を作り，PDF を添付する．

### 受け入れ条件

- `npm test` が通る．
- `npm run build` が `dist/book.pdf` を生成し，全ページが A6 判である．
- 本文ページの版面が指定の字数・行数で組まれている．
- 奇数ページの柱・ノンブルが左側，偶数ページが右側に出る．
- 扉・目次・奥付のページに柱・ノンブルが出ない．
- 原稿の会話文が天付きで，地の文が 1 字下げで組まれる．
- 2 桁の数字が縦中横で組まれる．

## スコープ外

- 表紙・裏表紙・背表紙のデータ生成．印刷所ごとの入稿要件に依存するため，書籍側で扱う．
- 紙入稿用の面付け・塗り足し・透明効果の除去．必要になった時点で
  `tomio2480/techbook-template` の実装を参照して追加する．
- 段組み（2 段組）．文庫本は 1 段組が標準である．
- 正誤表・版管理の仕組み．
- 索引．
